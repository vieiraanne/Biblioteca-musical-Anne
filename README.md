## 📌 Sobre o Projeto
Este projeto foi desenvolvido em equipe como atividade prática, utilizando HTML e CSS para criar um site com diferentes páginas de navegação e cadastro.

## 🚀 Funcionalidades
O projeto contém 5 telas principais:

- 🔐 **Login:** página de acesso ao sistema.
- 🏠 **Menu:** página principal com opções de navegação.
- 👤 **Cadastro do Criador:** formulário para cadastrar o criador.
- 📖 **Cadastro da Obra:** formulário para cadastrar uma obra.
- 📋 **Listagem:** exibição das obras cadastradas.

## 🎨 Design
- Um único arquivo `styles.css`.
- Paleta de cores de acordo com o tema escolhido pela equipe.
- Layout responsivo para computadores e celulares.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3

## 📂 Organização dos Arquivos
Os arquivos do projeto ficam organizados na raiz do repositório, sem pastas compactadas (.zip).

## 👥 Integrantes
Os nomes dos integrantes estão identificados em um comentário no início do arquivo `login.html`.

## ▶️ Como Executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `login.html` no navegador.
4. Navegue pelas telas utilizando os links disponíveis.
